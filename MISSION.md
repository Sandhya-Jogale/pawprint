# PawPrint MISSION

**Mission**: PawPrint is a community-driven platform dedicated to animal rescue and lost pet recovery. We empower communities to report sightings, find lost pets, and celebrate successful reunions.

## Tech Stack
- **Frontend**: React (Vite) / Tailwind CSS / TypeScript-ready 
*(Note: As we proceed, we can migrate to Next.js if preferred)*
- **Backend API**: Node.js / Express
- **Database**: PostgreSQL (with Prisma/pg)
- **Mapping**: Leaflet / React-Leaflet
- **Styling**: Tailwind CSS

## Primary Features
1. **Live Map**: Interactive geographical view showing real-time lost pet locations and community sightings.
2. **Sighting Reports**: Advanced forms with photo uploads, AI detection hooks, and detailed condition/location tracking.
3. **Success Stories**: Dedicated sections to highlight and celebrate reunited pets, fostering community engagement and social proof.
4. **Secure Authentication**: Dedicated portals for quick guest reporting and comprehensive dashboard access for registered users.
